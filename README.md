# 🌱 SAP ERP Implementation Project

### GreenHarvest Agro Pvt. Ltd.

#### *HCM | PP | WM Modules*

---

## 📌 Overview

This project presents a **complete implementation blueprint of SAP ERP** for a fictitious company **GreenHarvest Agro Pvt. Ltd.**, focusing on:

* 👨‍💼 Human Capital Management (HCM)
* 🏭 Production Planning (PP)
* 📦 Warehouse Management (WM)

Along with the theoretical implementation, the project also includes a **Java-based GUI simulation** demonstrating real-time interaction between these modules.

---

## 🏢 Company Profile

**GreenHarvest Agro Pvt. Ltd.** is an agriculture and food-processing company that manages:

* Organic production units 🌾
* Workforce operations 👥
* Warehouse & distribution systems 📦

The SAP system ensures **efficient coordination between workforce, production, and inventory**.

---

## ⚙️ Modules Implemented

### 🔹 HCM (Human Capital Management)

* Employee management
* Role assignment
* Workforce tracking

### 🔹 PP (Production Planning)

* Production execution
* Resource utilization
* Output generation

### 🔹 WM (Warehouse Management)

* Inventory tracking
* Stock updates
* Storage management

---

## 🔄 System Workflow

```text
HCM (Employees)
      ↓
PP (Production)
      ↓
WM (Inventory Update)
```

---

## 🖥️ GUI Simulation

The project includes a **Java Swing-based SAP simulation system**:

* 📋 HCM Tab → Add & manage employees
* 🏭 PP Tab → Execute production
* 📦 WM Tab → View inventory updates
